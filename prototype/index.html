1. 先看最小必要推导

3 步就够
Step 1
目标函数写成矩阵形式
J(w) = ‖y − Xw‖²₂
Step 2
对参数求导并令导数为 0
∇J(w) = -2Xᵀ(y - Xw) = 0
Step 3
得到正规方程并转成可实现形式
XᵀXw = Xᵀy ⟹ ŵ = (XᵀX)⁻¹Xᵀy
实现提醒

如果想让模型学到截距项,需要先把输入改成 X_b = [1, x] 的形式,也就是补一列全 1。

2. 你要实现什么

像做一个小型 ML coding task
函数签名
linear_regression(X, y) -> w
输入
二维特征矩阵 X 与目标向量 y
输出
包含截距项和系数的参数向量 w
检查点
是否补偏置列、矩阵乘法维度是否正确、结果是否能解释。

import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

np.random.seed(42)
X = np.random.rand(100, 1)
y = 4 + 3 * X.squeeze() + np.random.randn(100)*.5

model = LinearRegression()
model.fit(X, y)
print("w =", model.coef_[0], "b =", model.intercept_)
print("R² =", r2_score(y, model.predict(X)))

import numpy as np

def linear_regression(X, y):
    X_b = np.c_[np.ones((len(X),1)), X]
    w = np.linalg.inv(X_b.T@X_b) @ X_b.T@y
    return w
