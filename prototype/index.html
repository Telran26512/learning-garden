线性回归

Linear Regression 统计学习 线性模型
Stage 2 · Week 3 ● 公开 反向链接 12 处 关联:多元线性回归 · 最小二乘法 · 梯度下降法

数学推导

最小二乘目标:

J(w) = ‖y − Xw‖²₂

求导并令导数为 0:

−2Xᵀ(y − Xw) = 0

正规方程:

XᵀXw = Xᵀy

解:

ŵ = (XᵀX)⁻¹Xᵀy
查看完整推导 →

可运行代码 (Python)

import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score

np.random.seed(42)
X = np.random.rand(100, 1)
y = 4 + 3 * X.squeeze() + np.random.randn(100)*.5

model = LinearRegression()
model.fit(X, y)
print("w =", model.coef_[0], "b =", model.intercept_)
print("R² =", r2_score(y, model.predict(X)))
w = 2.98　b = 4.07　R² = 0.95

import numpy as np

def linear_regression(X, y):
    X_b = np.c_[np.ones((len(X),1)), X]
    w = np.linalg.inv(X_b.T@X_b) @ X_b.T@y
    return w

          

        

        

          差异:你的实现缺少偏置列 np.c_[np.ones(...), X],模型将没有截距项 b,只能拟合过原点的直线。
